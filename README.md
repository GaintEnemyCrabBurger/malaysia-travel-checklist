# 马来西亚出行清单（交互版）

Apple 风格的交互式出行清单，适配移动端。

## 在线访问

部署到 GitHub Pages 后，访问地址：
```
https://gaintEnemyCrabBurger.github.io/malaysia-travel-checklist/
```

## 部署步骤

1. **创建 GitHub 仓库**
   - 访问 https://github.com/new
   - 仓库名：`malaysia-checklist`
   - 选择 Public
   - 点击 "Create repository"

2. **上传文件**
   - 点击 "uploading an existing file"
   - 把 `index.html` 拖进去
   - 点击 "Commit changes"

3. **开启 GitHub Pages**
   - 进入仓库的 Settings → Pages
   - Source 选择 "Deploy from a branch"
   - Branch 选择 "main" 和 "/ (root)"
   - 点击 Save

4. **等待部署**
   - 1-2 分钟后刷新页面
   - 会显示你的网站地址
   - 点击访问即可

## 本地使用

也可以直接用浏览器打开 `index.html` 文件。

## 添加到手机主屏幕

**iOS Safari:**
1. 打开网站
2. 点击分享按钮
3. 选择"添加到主屏幕"
4. 像 App 一样使用

**Android Chrome:**
1. 打开网站
2. 点击菜单（三个点）
3. 选择"添加到主屏幕"
